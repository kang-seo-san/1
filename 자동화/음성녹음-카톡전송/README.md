# 음성녹음 → 카카오톡 나에게 자동 전송 (통화녹음 제외)

## 개요
- 대상: 갤럭시 + 삼성 '음성 녹음' 앱
- 결과: 새 녹음이 저장되면 카톡 '나와의 채팅'에 **파일명·녹음시각·용량 + [녹음 열기] 링크**가 옴
- 통화녹음 제외 방식 (2중)
  - 1차: 통화녹음 폴더(`Recordings/Call`)는 동기화하지 않음
  - 2차: 파일 이름에 `통화`, `Call`이 들어간 파일은 스크립트가 걸러냄
- 비용: 무료 (구글 계정, 카카오 계정만 있으면 됨)
- 소요 시간: 처음 설정 약 30분, 이후 자동

```
[갤럭시] 음성녹음 → Recordings/Voice Recorder 폴더
   ↓ ① 동기화 앱 (이 폴더만 업로드)
[구글드라이브] '음성녹음' 폴더
   ↓ ② 구글 Apps Script (5분마다 확인)
[카카오톡] 나와의 채팅으로 링크 전송
```

> 왜 파일이 아니라 링크인가: 카카오 공식 '나에게 보내기' 기능(API)은 글·링크만 보낼 수 있고 파일 첨부는 지원하지 않음.
> 링크를 누르면 구글드라이브에서 바로 재생·다운로드됨.

---

## 1단계. 녹음 저장 위치 확인 (휴대폰)
- '내 파일' 앱 → 내장 저장공간 → `Recordings` 폴더
  - `Voice Recorder` : 음성녹음 앱 파일 ← **이 폴더만 사용**
  - `Call` : 통화녹음 파일 ← 제외
- 폴더 이름이 다르면(구형 기종은 `Sounds` 폴더 등) 실제 위치를 메모해 둠

## 2단계. 구글드라이브 자동 업로드 설정 (휴대폰)
- 구글드라이브에 `음성녹음` 폴더 만들기
- Play 스토어에서 **Autosync for Google Drive** 설치 (무료)
- 앱 실행 → 구글 계정 연결 → 폴더 쌍(Folder pair) 만들기
  - 휴대폰 폴더: `Recordings/Voice Recorder`
  - 구글드라이브 폴더: `음성녹음`
  - 동기화 방식: **업로드만 (Upload only)** ← 드라이브에서 지워도 휴대폰 원본은 안전함
- 앱 설정에서 '즉시 동기화(Instant sync)' 켜기
- 휴대폰 설정 → 애플리케이션 → Autosync → 배터리 → **제한 없음** (안 하면 업로드가 늦어짐)
- 테스트: 짧게 녹음 → 1~2분 내 드라이브 `음성녹음` 폴더에 올라오는지 확인

## 3단계. 카카오 개발자 앱 만들기 (PC 권장)
'카카오에 내 프로그램을 등록해서 카톡 보낼 권한을 받는 과정'임.

1. https://developers.kakao.com 접속 → 카카오 계정 로그인
2. 내 애플리케이션 → 애플리케이션 추가 (앱 이름 예: `녹음알림`)
3. 앱 키 → **REST API 키** 복사해 둠
4. 플랫폼 → Web 플랫폼 등록 → 사이트 도메인에 `https://drive.google.com` 입력
   - 이걸 안 하면 카톡 메시지의 링크가 눌리지 않음
5. 카카오 로그인 → 활성화 **ON** → Redirect URI에 `https://localhost` 등록
6. 카카오 로그인 → 동의항목 → **카카오톡 메시지 전송** → '선택 동의'로 설정
7. (보안 → Client Secret이 '사용함'이면 코드 값도 복사해 둠)

## 4단계. 인가코드 받기 (1회용)
- 아래 주소에서 `REST_API_키` 부분만 바꿔 브라우저 주소창에 입력

```
https://kauth.kakao.com/oauth/authorize?client_id=REST_API_키&redirect_uri=https://localhost&response_type=code&scope=talk_message
```

- 동의 화면 → '카카오톡 메시지 전송' 체크 → 동의
- '사이트에 연결할 수 없음' 화면이 뜨는 게 **정상**임
- 주소창의 `https://localhost/?code=` **뒤의 긴 글자**를 복사 (이게 인가코드)
- 인가코드는 몇 분 안에 만료되므로 바로 5단계 진행

## 5단계. 구글 Apps Script 설정 (PC 권장)
'구글이 대신 돌려주는 작은 프로그램'임. 내 PC를 꺼 놔도 돌아감.

1. https://script.google.com → 새 프로젝트 → 이름 `음성녹음 카톡전송`
2. 기본 코드 전부 지우고 `Code.gs` 내용 전체 붙여넣기
3. 맨 위 `CONFIG` 부분 수정
   - `KAKAO_REST_API_KEY` : 3단계 REST API 키
   - `KAKAO_CLIENT_SECRET` : 3-7단계 값 (없으면 비워둠)
   - `AUTH_CODE` : 4단계 인가코드
4. 저장(💾) 후, 위쪽 함수 선택 칸에서 아래 순서대로 하나씩 골라 **실행**
   1. `setup_1_카카오토큰발급`
      - 처음 실행 시 권한 요청 창 → 계정 선택 → '고급' → '(안전하지 않음)으로 이동' → 허용
      - (내가 만든 스크립트라 구글이 검증 안 했다는 뜻이며 정상임)
   2. `setup_2_테스트메시지` → 카톡 나와의 채팅에 테스트 메시지 오는지 확인
   3. `setup_3_자동실행시작` → 이후 5분마다 자동 확인 시작
5. 완료. 휴대폰으로 녹음해서 5~10분 내 카톡이 오는지 확인

---

## 알아둘 점
- 전송 지연: 업로드(1~2분) + 확인 주기(최대 5분) → 보통 **10분 이내**
- 기존 녹음: `setup_3` 실행 시점에 이미 있던 파일은 보내지 않음 (예전 파일 폭탄 방지)
- 링크 보안: 파일은 '나만 보기' 상태 그대로임. 링크를 남에게 보내도 내 구글 계정 로그인 없이는 못 열음
- 토큰 만료: 카카오 권한은 약 2개월마다 자동 연장됨. 2개월 넘게 녹음이 전혀 없어 끊기면 4~5단계(`setup_1`)만 다시 하면 됨
- 오류 확인: Apps Script 왼쪽 메뉴 '실행' 기록에서 빨간색 실패 내역 확인 가능. 실패한 파일은 다음 실행 때 다시 시도함
- 제외 단어 추가: `CONFIG.EXCLUDE_KEYWORDS`에 단어 추가 (예: `'녹취'`)
